Sobre seus dados

As viagens e rotas disponíveis atualmente são registros operacionais compartilhados do sistema. O modelo atual ainda não relaciona uma viagem à conta que a criou ou que deve acompanhá-la; por isso, o painel não apresenta viagens globais como se fossem pessoais.

Para exibir próximas viagens, histórico e reservas exclusivamente desta conta, será necessário implementar a associação entre usuário e viagem na API e no banco de dados.
